# sop-builder: Write an SOP from process notes

Turns a description, recording transcript or notes of how a process is done into a step-by-step SOP and a one-page checklist.

| | |
|---|---|
| **You give it** | A description, screen-recording transcript, Loom notes, or rough notes of how a process is done |
| **You get back** | A standard operating procedure (purpose, scope, roles, SIPOC, steps with owners and checks, common mistakes, open questions) plus a one-page checklist |
| **Method** | SIPOC (Suppliers, Inputs, Process, Outputs, Customers) + step/owner/check format |
| **Search terms** | SOP template, standard operating procedure, process documentation, SIPOC, onboarding checklist |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
