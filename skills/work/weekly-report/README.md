# weekly-report: Weekly status report for your manager

Turns a week of task lists, notes, tickets and messages into a bottom-line-first weekly report with Progress, Plans and Problems.

| | |
|---|---|
| **You give it** | Task lists, notes, tickets, commits, chat messages, calendar from the week |
| **You get back** | A weekly report (bottom line, progress, plans, problems and asks, metrics if provided) plus a 3-line version for chat |
| **Method** | PPP (Progress, Plans, Problems) + bottom line first |
| **Search terms** | weekly report template, weekly status update, progress report to manager, PPP report, weekly update email |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
