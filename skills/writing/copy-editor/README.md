# copy-editor: Copy edit with a change log

Turns a near-final text into a clean copy with a tracked change log, a style sheet and queries for the author.

| | |
|---|---|
| **You give it** | A near-final draft and, optionally, a house style guide or AP, Chicago or APA |
| **You get back** | A clean copy, a change log (before, after, reason), a style sheet of decisions, and author queries |
| **Method** | Copy-editing checklist, editorial style sheet |
| **Search terms** | copy editing, proofread my document, style guide check, AP style checker, consistency check |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
