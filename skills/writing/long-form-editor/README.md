# long-form-editor: Edit essays, articles and reports

Turns a long draft into an edited version through developmental, line and copy passes, with a prioritised change list.

| | |
|---|---|
| **You give it** | A long draft: essay, article, report, thesis chapter, white paper |
| **You get back** | A reverse outline, a prioritised change list by editing level, a style sheet and the edited version |
| **Method** | Three levels of editing (developmental, line, copy), reverse outlining |
| **Search terms** | edit my essay, developmental editing, line editing, reverse outline, structural edit report |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
