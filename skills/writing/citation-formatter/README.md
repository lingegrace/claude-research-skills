# citation-formatter: Reference list formatter and citation checker

Turns a messy reference list into clean APA, Harvard, Chicago, MLA, IEEE or GB/T 7714 references and checks every in-text citation against it.

| | |
|---|---|
| **You give it** | A messy reference list, in-text citations or the full manuscript, and the target style |
| **You get back** | Formatted reference list, in-text citation cross-check, list of entries with missing information, summary of changes |
| **Method** | Published rules of APA 7, Harvard, Chicago author-date, MLA 9, IEEE and GB/T 7714 |
| **Search terms** | APA 7 reference formatter, citation generator, Harvard referencing, check citations against reference list, GB/T 7714 format |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
