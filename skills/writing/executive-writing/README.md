# executive-writing: Executive summary and BLUF emails

Turns notes, a long update or an email thread into an executive-ready message with the bottom line first and a clear ask.

| | |
|---|---|
| **You give it** | Meeting notes, a long status update, an analysis, or an email thread |
| **You get back** | An executive email or update with the bottom line, explicit ask and three supporting points, plus one-paragraph and one-line versions |
| **Method** | BLUF, Minto Pyramid Principle, SCQA |
| **Search terms** | executive summary email, BLUF email, Minto Pyramid Principle, SCQA framework, write an update for leadership |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
