# thematic-analysis: Thematic analysis (Braun & Clarke)

Runs reflexive thematic analysis on transcripts: a codebook with located quotes, reviewed themes and a write-up with an audit trail.

| | |
|---|---|
| **You give it** | Interview transcripts, focus groups, open-ended survey answers, field notes |
| **You get back** | Codebook, thematic map, defined themes with exact quotes, methods paragraph, reflexivity note and audit trail |
| **Search terms** | thematic analysis, Braun and Clarke, qualitative coding, codebook, qualitative data analysis |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
