# skill-creator: Write your own Claude skill

Turns a task you repeat at work, with real input and output examples, into a ready SKILL.md, README and test plan.

| | |
|---|---|
| **You give it** | A description of a job you repeat, plus real examples of what you start from and what you hand in |
| **You get back** | A complete SKILL.md draft (name, description, steps with done-conditions, output template, rules), a README and a test plan |
| **Method** | 4-part skill anatomy (trigger, steps with done-conditions, output template, rules), built from real input and real output |
| **Search terms** | create a Claude skill, how to write a SKILL.md, Claude skill template, custom AI skill, Agent Skills tutorial |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.

- Skill instructions: [SKILL.md](SKILL.md)

Install the whole collection in Claude Code with `/plugin marketplace add lingegrace/claude-research-skills`, or upload [skill-creator.zip](../../../dist/skill-creator.zip) in Claude.ai under Settings → Capabilities → Skills. See the [main README](../../../README.md).
