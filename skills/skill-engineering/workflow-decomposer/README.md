# workflow-decomposer: Find where AI fits in your work

Turns a job role or recurring piece of work into stages with inputs and outputs, an AI-versus-human judgement per stage, and a map of skills to build.

| | |
|---|---|
| **You give it** | A role or a recurring task (e.g. monthly marketing report, customer interview programme), plus any templates, past examples or checklists |
| **You get back** | A task hierarchy, each stage's input, output and done-condition, AI fit per stage (AI skill, AI + review, human) and a skill map with a build order |
| **Method** | Hierarchical task analysis (HTA), input-output mapping |
| **Search terms** | workflow automation with AI, task analysis, where to use AI at work, process mapping, hierarchical task analysis |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
