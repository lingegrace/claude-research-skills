# feature-spec: User stories and acceptance criteria

Turns an approved PRD or feature description into an engineering-ready spec with Given/When/Then acceptance criteria.

| | |
|---|---|
| **You give it** | An approved PRD, a feature description, design notes |
| **You get back** | User stories with Given/When/Then acceptance criteria, edge cases, empty/loading/error states, analytics events, dependencies, rollout plan and open questions |
| **Method** | User stories + Gherkin-style acceptance criteria (Given/When/Then) |
| **Search terms** | user story template, acceptance criteria examples, given when then, feature specification, PRD to Jira tickets |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
