# product-discovery: Opportunity solution tree and assumption tests

Turns a desired outcome and what you already know into an opportunity solution tree, an assumption map and the next 3 cheapest experiments.

| | |
|---|---|
| **You give it** | A desired outcome (e.g. increase activation) plus data, interview notes, feedback, support tickets |
| **You get back** | An opportunity solution tree (outcome → opportunities → solutions → assumption tests), an assumption map (desirability, viability, feasibility, usability) and the next 3 cheapest experiments |
| **Method** | Opportunity Solution Tree (Teresa Torres) + assumption mapping |
| **Search terms** | opportunity solution tree, continuous discovery, product discovery framework, assumption mapping, Teresa Torres |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
