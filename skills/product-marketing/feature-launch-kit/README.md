# feature-launch-kit: Feature launch & GTM kit

Turns a PRD or changelog into release notes, a customer announcement, sales one-pager, support FAQ and social posts that all agree on the facts.

| | |
|---|---|
| **You give it** | PRD, spec, Jira epic, changelog, release notes |
| **You get back** | Fact sheet plus every launch piece for the launch tier: release notes, in-app message, announcement, sales one-pager, FAQ, internal email, social posts |
| **Search terms** | product launch, go-to-market, GTM, release notes, launch announcement |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.

- Skill instructions: [SKILL.md](SKILL.md)

Install the whole collection in Claude Code with `/plugin marketplace add lingegrace/claude-research-skills`, or upload [feature-launch-kit.zip](../../../dist/feature-launch-kit.zip) in Claude.ai under Settings → Capabilities → Skills. See the [main README](../../../README.md).
