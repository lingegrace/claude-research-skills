# value-proposition-writer: Value proposition writer — features to benefits (FAB)

Turns a PRD, spec or feature list into a Feature–Advantage–Benefit analysis grounded in your audience, their pain points and the competition.

| | |
|---|---|
| **You give it** | PRD, product spec, feature list, landing page, pitch deck |
| **You get back** | FAB matrix per audience, value proposition, gaps to fix, and optionally the finished PRD value section or one-pager |
| **Search terms** | product value proposition, FAB analysis, features advantages benefits, PRD value section, sales one-pager copy |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
