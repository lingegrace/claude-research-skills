# content-repurposing: Repurpose content across channels

Turns one article, report, webinar or newsletter into LinkedIn, X, newsletter, carousel, video and email versions that keep the same message.

| | |
|---|---|
| **You give it** | One source piece (article, report, webinar transcript, newsletter, podcast notes) and the channels you post on |
| **You get back** | The key message, a version per channel, and a message integrity check table confirming each keeps the core claim, audience and CTA |
| **Method** | Key message extraction, per-channel adaptation, message integrity check |
| **Search terms** | content repurposing, repurpose blog post, turn article into LinkedIn post, content distribution, webinar to social posts |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
