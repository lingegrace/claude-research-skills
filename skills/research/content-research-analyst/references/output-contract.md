# Research Analyst — Output Contract

The Skill should return a Markdown Research Brief with these required sections:

1. Executive Summary
2. Source Register
3. Key Claims and Evidence
4. Cross-source Synthesis
5. Creator-useful Insights
6. Gaps and Follow-up Research
7. Content Handoff
8. Source Notes

Minimum traceability requirements:
- Stable source IDs (S1, S2, ...)
- Claim IDs (C1, C2, ...)
- A source ID and locator for every material factual claim
- Explicit `Not provided` / `Not verified` for missing metadata
- Publication date separated from event/data period
- Confidence and caveat fields for extracted claims
- Distinction between reported fact, source interpretation, synthesis, inference, and user perspective

Default language: English. If bilingual is requested, provide English main output and a Chinese summary without changing the strength or certainty of claims.
