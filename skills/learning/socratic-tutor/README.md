# socratic-tutor: Learn any topic by Socratic questioning

Turns a topic you want to understand into a question-by-question tutoring session that builds on what you already know.

| | |
|---|---|
| **You give it** | A topic or concept you want to understand, and what you already know about it |
| **You get back** | A tutoring session, one question at a time, with misconceptions corrected through questions and a short summary at the end |
| **Method** | Socratic questioning, Paul and Elder's question types |
| **Search terms** | Socratic method tutor, learn by questioning, explain concept step by step, oral exam practice, 苏格拉底式提问 |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
