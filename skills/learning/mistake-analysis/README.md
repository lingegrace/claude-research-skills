# mistake-analysis: Mistake notebook and error analysis

Turns the wrong answers from your homework, tests or past papers into an error log by cause, patterns, targeted practice and a retest.

| | |
|---|---|
| **You give it** | Wrong answers from homework, tests or past papers (any subject), with correct answers and marks if you have them |
| **You get back** | An error log with each mistake's cause, the patterns that cost you most, targeted practice, and a retest set |
| **Method** | Error analysis, deliberate practice, retesting |
| **Search terms** | mistake notebook, error analysis exam, why do I keep making mistakes, past paper review, 错题本 错题归因 |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
