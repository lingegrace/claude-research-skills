# transfer-practice: Apply what you learned to new problems

Turns something you have studied into practice problems in new contexts, from a worked example to solving on your own.

| | |
|---|---|
| **You give it** | A concept, formula, framework or skill you've studied, and where you need to use it |
| **You get back** | A worked example, a faded practice sequence from near to far transfer, feedback on each attempt, and review problems |
| **Method** | Transfer of learning (near and far transfer), worked examples, faded scaffolding |
| **Search terms** | apply concepts to new problems, practice problems generator, worked examples, exam application questions, 举一反三练习 |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
