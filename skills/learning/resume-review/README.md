# resume-review: Resume review against a job description

Turns your CV and a target job description into a match review, bullet-by-bullet impact check and rewrites that use only your real facts.

| | |
|---|---|
| **You give it** | Your CV or resume and the job description you're applying for |
| **You get back** | A JD keyword and skill match, impact rating for each bullet, structure and ATS readability fixes, rewritten bullets, and questions for missing metrics |
| **Method** | JD requirement and keyword matching, action + result + metric bullet writing (XYZ formula) |
| **Search terms** | resume review, tailor resume to job description, ATS resume check, rewrite resume bullets, 简历修改 |

It always starts by asking what you're trying to achieve and what you already have, then works through fixed steps. Every claim is traced to your material or labeled as an assumption.
